# 🔥 AI Fire & Smoke Detection System

YOLOv11 based Fire and Smoke Detection System with Streamlit Dashboard.

## 🚀 Features

- 🔥 Fire Detection
- 🌫 Smoke Detection
- 🎯 Bounding Box Visualization
- 📊 Confidence Score
- 🌐 Streamlit Web Application

## 🛠 Tech Stack

- Python
- YOLOv11
- Ultralytics
- PyTorch
- OpenCV
- Streamlit
