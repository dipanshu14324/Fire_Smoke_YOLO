# 🔥 AI Fire & Smoke Detection System

YOLOv11 based Fire and Smoke Detection System with Streamlit Dashboard.

## 🚀 Features

- 🔥 Fire Detection
- 🌫 Smoke Detection
- 🎯 Bounding Box Visualization
- 📊 Confidence Score
- 🌐 Streamlit Web Application

## 🛠 Tech Stack

- Python
- YOLOv11
- Ultralytics
- PyTorch
- OpenCV
- Streamlit

## 📊 Dataset

The model was trained on a Fire and Smoke detection dataset containing:

- Fire images
- Smoke images
- Annotated bounding boxes
- YOLO format labels

Dataset split:

- Training set
- Validation set
- Testing set



## 🤖 Model Details

Model: YOLOv11 Object Detection

Task:
- Object Detection

Classes:
- Fire
- Smoke

Input:
- Images

Output:
- Bounding boxes
- Class prediction
- Confidence score



## 🏋️ Training

Training workflow:

1. Dataset preprocessing
2. YOLO annotation verification
3. YOLOv11 model training
4. Model evaluation
